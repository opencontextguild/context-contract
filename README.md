# Context Contract

**Machine-readable agreements on the meaning, validity and permitted use of context for AI agents.**

> *Can the same business ontology and the same Context Contract be used, without semantic redesign, by agents on two independent platforms?*
> — our primary architectural criterion

Google, W3C and open communities are each building a piece of the context layer for AI: OKF for packaging knowledge, Context Graphs for interpretation, ODRL and SKOS for rules and meaning. The Context Contract works where those pieces meet. It covers whether **this** agent may use **this** context for **this** task, and how you can prove that across vendors.

Status: **early draft** (v0.1 in preparation). Stewarded by the [Open Context Guild](https://opencontextguild.org) (Stichting Bewakers van Betekenis i.o., Netherlands).
